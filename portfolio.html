Project 1

This project analyzes U.S. flight delay data to see whether certain airports are more prone to specific types of delays. The goal is to uncover patterns, such as northern airports facing more weather delays and major hubs experiencing more carrier or airspace-related delays..

Project 2

This project explores whether machine learning can predict the presence of heart disease based on patient medical and demographic features such as age, cholesterol, blood pressure, and chest pain type. Using a heart disease dataset, I applied classification algorithms, evaluated their performance, and identified the most important factors that influence predictions.

View Project
Project 3

This project estimates home sale prices using regression on the Ames, Iowa dataset from Kaggle. I explore data quality and key drivers (overall quality, living area, year built, neighborhood), build a linear baseline, and evaluate accuracy with RMSE on log prices.

View Project
Project 4

This project applies clustering techniques to analyze credit card customer data and uncover hidden patterns in spending and payments. Using K-Means and Agglomerative Clustering, I identified distinct groups such as high spenders, low users, and cash-advance customers. The results highlight how unsupervised learning can reveal meaningful insights about financial behavior.

View Project
Project 5

This project builds a hybrid recommendation system that helps users discover movies and TV shows similar to ones they love. Using content-based filtering with TF-IDF and cosine similarity combined with IMDb ratings, the system suggests relevant, high-quality titles. Try the interactive demo to explore recommendations!
