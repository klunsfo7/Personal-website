iOS App: Meadow Grove Church App

A SwiftUI app built for a church community to make key info easy to find—service times, events, announcements, and dynamic content that leadership can update.

SwiftUI Backend API Announcements Push Notifications

At a glance

  • Tab layout: Home, Announcements, Prayer, Profile
  • Home feed loads sections/cards from an API (with a static fallback)
  • Leader tools to create/update cards and post announcements
  • Remote push registration (APNs token → backend)

What it does

This app is designed to be a simple “home base” for the church. The Home tab presents service times, classes, outreach items, and upcoming events. When the backend is available, the Home page can be driven by admin-managed sections and cards; otherwise it falls back to a built-in layout.

Key features

Dynamic home content

Fetches sections/cards from an API so content can be updated without an App Store release.

Service & event details

Tap cards to view detail pages (time/day/notes + richer info when provided by the backend).

Announcements

New/old announcement lists, detail view, and leader actions to create/archive/delete.

Push notifications

Registers the device token with the backend to support server-driven notifications.

Accounts & roles

Login/create account; leader role unlocks editing tools for content management.

Settings

Appearance settings, legal pages, support email links, and account deletion.

How it works (high level)

  • Home loads sections/cards from a backend API, with a built-in fallback UI if no sections load.
  • Announcements are fetched from the backend and can optionally link to a specific “card” detail page.
  • Leader mode enables card creation/editing and announcement management.
  • Push requests notification permission, registers with APNs, then sends the device token to the backend.

Tech stack

Frontend
SwiftUI (tabs, navigation, custom card UI)
Backend integration
REST API calls (home content, announcements, auth)
Notifications
APNs registration + token upload to backend
Backend hosting
Configured for a Render deployment URL

Codebase notes

The iOS project is in MeadowGroveApp copy/. There’s also a backend folder (MeadowGroveApp copy/Swift_Backend/) used to support the API and notifications pipeline.
