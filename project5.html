Project 5: Streaming Recommendation System

Building a hybrid content and rating-based recommender system for movies and TV shows.

Project Five

Introduce the Problem

In the age of streaming services like Netflix, Hulu, Disney+, and Amazon Prime, users are overwhelmed with thousands of movies and TV shows to choose from. With so much content available, finding something new to watch that matches your interests can be surprisingly difficult. This phenomenon, known as "choice paralysis," often leads to users spending more time browsing than actually watching.

This project addresses that challenge by building a recommendation system that helps users discover movies and TV shows similar to ones they already love. The system uses a hybrid approach combining content-based filtering (analyzing genres, descriptions, and metadata) with collaborative filtering (leveraging ratings and popularity) to surface relevant recommendations.

The central question is: Can we build an effective recommender system that accurately suggests titles based on content similarity and viewer preferences? By analyzing a large dataset of streaming titles with metadata such as genres, descriptions, IMDb scores, and vote counts, this project demonstrates how machine learning and natural language processing can improve content discovery and enhance user experience in the streaming entertainment landscape.

What is a Recommendation System?

A recommendation system is a type of information filtering algorithm designed to predict and suggest items that a user might be interested in. These systems are widely used across the internet — from suggesting products on Amazon to recommending songs on Spotify and videos on YouTube. The goal is to personalize the user experience by surfacing relevant content from a vast catalog.

Types of Recommendation Systems

There are several approaches to building recommender systems:

  • Content-Based Filtering: Recommends items similar to what the user has liked before by analyzing item features (e.g., genres, keywords, descriptions). If you enjoyed a sci-fi thriller, the system suggests other sci-fi thrillers.
  • Collaborative Filtering: Recommends items based on what similar users have liked. If users with similar viewing histories enjoyed a particular show, you're likely to enjoy it too.
  • Hybrid Approaches: Combine content-based and collaborative methods to leverage the strengths of both, providing more accurate and diverse recommendations.
How This Project Works

This project implements a hybrid recommendation system using natural language processing (NLP) and weighted scoring. It analyzes textual features like genres and descriptions using TF-IDF (Term Frequency-Inverse Document Frequency) vectorization combined with cosine similarity to find content matches. Additionally, it incorporates IMDb scores and vote counts using a weighted rating formula to surface not just similar titles, but also high-quality, popular ones that viewers are more likely to enjoy.

The system also supports genre-based search, allowing users to explore top-rated titles within specific genres, making it versatile for different discovery needs.

Introduce the Data

The dataset used for this project is a comprehensive collection of movies and TV shows available on various streaming platforms. It includes detailed metadata for each title, such as genres, descriptions, IMDb ratings, vote counts, release years, and content types (movie or show). This rich dataset provides the foundation for building an effective content-based recommendation system.

Data Source

The dataset was sourced from publicly available streaming catalogs and IMDb data, aggregated to represent a diverse collection of entertainment content. Each record represents a unique title with associated metadata that describes its content and popularity.

Key Features

The most important features in the dataset include:

  • Title – The name of the movie or TV show.
  • Type – Whether the content is a movie or a TV show.
  • Genres – Categories describing the content (e.g., Drama, Comedy, Action, Sci-Fi).
  • Description – A text summary describing the plot or premise of the title.
  • IMDb Score – The average rating (0-10) from IMDb users, indicating overall quality.
  • IMDb Votes – The number of user votes, indicating popularity and reliability of the rating.
  • Release Year – The year the title was released.
Why This Dataset Works Well for Recommendations

The dataset's combination of textual features (genres and descriptions) and numerical ratings makes it ideal for a hybrid recommendation approach. The textual data enables content-based similarity matching, while the rating and vote data allow for quality-weighted ranking. This ensures that recommendations are not only similar in content but also reflect viewer preferences and quality standards.

Additionally, the dataset's large size and diversity provide broad coverage across genres and content types, making the system useful for a wide variety of user preferences and discovery scenarios.

Data Understanding/Visualization

Before building the recommendation system, I explored the dataset to understand its structure, quality, and distribution. The dataset contains thousands of titles spanning various genres, release years, and quality levels. Initial inspection revealed that IMDb scores are generally distributed between 5.0 and 8.5, with most titles having moderate ratings, and a smaller number of exceptionally high or low-rated titles.

Key Insights from Exploration

Genre analysis showed that Drama, Comedy, and Action are the most common genres, often appearing in combination with others. The distribution of IMDb votes revealed significant variation — some titles have millions of votes (indicating widespread popularity), while others have just a few thousand. This variance is important for the weighted scoring mechanism, which balances raw ratings with vote count credibility.

Text analysis of descriptions showed that certain keywords and themes are strongly associated with specific genres. For example, "crime," "detective," and "murder" frequently appear in thriller and mystery descriptions, while "love," "family," and "life" are common in dramas and comedies. This natural clustering of language patterns validates the use of TF-IDF vectorization for content similarity.

How This Relates to Modeling

Understanding these patterns informed the choice of features and preprocessing steps. The textual features (genres and descriptions) needed to be combined and vectorized for similarity calculations, while the rating features required a weighted formula to ensure recommendations favor both similar content and high-quality titles. The insights from data exploration confirmed that a hybrid approach would be most effective.

Pre-processing the Data

Before building the recommendation engine, the data needed to be cleaned and transformed to ensure accurate similarity calculations and quality scoring. Several preprocessing steps were applied to prepare the dataset for modeling.

Pre-processing Steps
  • Handle Missing Values: Titles with missing descriptions or genres were either filled with placeholder text or removed, ensuring all records have usable content for similarity matching.
  • Text Normalization: Descriptions were converted to lowercase, and special characters were removed to standardize text for NLP processing.
  • Genre Parsing: Genre strings (often stored as comma-separated lists) were split and processed into consistent formats for filtering and similarity calculations.
  • Feature Engineering: Combined genres and descriptions into a single text field for TF-IDF vectorization, creating a unified content representation for each title.
  • Weighted Score Calculation: Computed a weighted rating for each title using a formula that balances IMDb score with vote count credibility, similar to IMDb's weighted rating formula.
Why These Steps Matter

Text normalization and feature engineering ensure that the TF-IDF vectorizer can accurately capture content similarity without being skewed by inconsistent formatting or missing data. The weighted score calculation is crucial for ranking recommendations — it ensures that titles with high ratings but few votes (which might be unreliable) are balanced against titles with moderate ratings but strong viewer consensus.

These preprocessing steps create a clean, consistent dataset ready for similarity calculations and quality-based ranking, forming the foundation of an effective hybrid recommendation system.

Building the Recommendation Engine

The recommendation system was built using a hybrid approach that combines content-based similarity with quality-weighted ranking. The process involved vectorizing textual features, computing similarity scores, and incorporating rating data to surface the best recommendations.

TF-IDF Vectorization and Cosine Similarity

To measure content similarity, I used TF-IDF (Term Frequency-Inverse Document Frequency) vectorization on the combined genre and description text for each title. TF-IDF converts text into numerical vectors that reflect the importance of words within each document relative to the entire dataset. Titles with similar vocabulary and themes will have similar vectors.

Cosine similarity was then computed between title vectors to identify the most similar content. This metric ranges from 0 (completely dissimilar) to 1 (identical), providing a straightforward way to rank titles by content similarity. For each title, the system identifies the top matches based on these similarity scores.

Weighted Rating Formula

To ensure recommendations include not just similar content but also high-quality titles, I implemented a weighted rating formula inspired by IMDb's Top 250 methodology. The formula balances the raw IMDb score with the number of votes, giving more weight to titles with strong viewer consensus:

Weighted Score = (v / (v + m)) × R + (m / (v + m)) × C

Where v is the vote count, m is the minimum votes threshold, R is the average rating, and C is the mean rating across all titles. This ensures that highly-rated titles with few votes don't outrank moderately-rated titles with strong consensus.

Combining Content and Quality

The final recommendation list for each title is generated by first finding the most similar titles based on content (cosine similarity), then sorting them by weighted score to prioritize quality. This hybrid approach ensures that users receive recommendations that are both relevant in content and likely to be enjoyable based on viewer ratings.

Genre-Based Search

In addition to title-based recommendations, the system supports genre-based search, allowing users to explore top-rated titles within specific genres or genre combinations. This is done by filtering titles that match all specified genres, then ranking them by weighted score. This feature provides an alternative discovery mode for users who want to explore a particular type of content.

Results and Demo

The recommendation system successfully generates relevant, high-quality recommendations for movies and TV shows. When tested with popular titles like "Breaking Bad," the system accurately suggests similar crime dramas with strong ratings, such as "Better Call Saul" and "The Wire." For genre-based searches, entering "Action, Sci-Fi" returns top-rated titles like "The Matrix" and "Inception."

Key Findings

The system's ability to suggest both title-based and genre-based recommendations makes it versatile and user-friendly, catering to different discovery patterns and preferences.

Impact Section

Recommendation systems have become an integral part of the digital economy, influencing what we watch, listen to, read, and buy. While they offer clear benefits in helping users discover content and improving engagement, they also raise important ethical and social considerations that must be carefully managed.

Potential Positive Impacts
  • Improved User Experience: Helps users navigate overwhelming content catalogs and discover titles they're likely to enjoy, reducing decision fatigue.
  • Content Discovery: Surfaces lesser-known titles that match user preferences, promoting diverse content and supporting creators of niche content.
  • Business Value: Increases user engagement and satisfaction, which translates to higher retention and revenue for streaming platforms.
  • Personalization: Creates tailored experiences that respect individual preferences and viewing habits, making entertainment more accessible.
Potential Negative Impacts & Concerns
  • Filter Bubbles: Over-reliance on recommendations can create echo chambers where users only see content similar to what they've already consumed, limiting exposure to diverse perspectives and new genres.
  • Algorithmic Bias: If training data reflects historical biases (e.g., underrepresentation of certain cultures or voices), the system may perpetuate these biases by under-recommending diverse content.
  • Privacy Concerns: Recommendation systems rely on collecting detailed user behavior data, raising concerns about data privacy, consent, and potential misuse of viewing history information.
  • Manipulation and Exploitation: Recommendation algorithms optimized purely for engagement might prioritize sensational or addictive content over quality, potentially exploiting psychological vulnerabilities.
  • Content Creator Impact: Smaller creators or unconventional content may struggle to get recommended if algorithms favor established, popular titles, potentially stifling innovation and diversity in entertainment.
Ethical Considerations & Responsible Use

To use recommendation systems responsibly, developers and platforms should prioritize transparency, allowing users to understand why certain titles are recommended. Systems should also incorporate mechanisms for serendipity and diversity, occasionally suggesting content outside the user's typical preferences to prevent filter bubbles. Privacy protections and clear data usage policies are essential to maintain user trust.

Additionally, recommendation systems should be regularly audited for bias and fairness, ensuring that content from diverse creators and perspectives receives equitable visibility. When designed and deployed thoughtfully, recommendation systems can enhance user experience while respecting individual autonomy and promoting a healthy, diverse media ecosystem.
